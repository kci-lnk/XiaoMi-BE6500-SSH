# 小米 BE6500 SSH 工具

已有 root SSH 的主路由或 Mesh 子节点，可以直接验证登录。请使用该节点自己的地址和 SSH 凭据。

```sh
./miwifi-ssh.sh --check 192.168.31.1
```

脚本调用系统 OpenSSH，保留主机密钥校验，执行 `id -u`。仅当命令成功且输出为 `0` 时返回成功。连接超时、密码错误或远端身份验证失败均返回非零。支持 macOS 和 Linux，需要 `ssh`。

## 旧版交互流程

运行 `./miwifi-ssh.sh` 会使用仓库原有的固件接口，依次询问管理会话 STOK、路由器地址和序列号。此路径会修改设备配置，还需要 curl、Python 3 和 OpenSSL。接口返回错误、HTTP 请求失败或响应无法解析时，脚本立即退出。部分步骤可能已经生效；重新操作前可先使用 `--check` 查看实际状态。

在 RN02 固件 1.0.64 的实测中，旧接口返回了 `1523`。当前脚本没有为该固件新增开启接口。旧流程的候选密码输出也不能证明 SSH 已启动，最后仍需实际登录验证。MIT 许可证见 [LICENSE](LICENSE)。
